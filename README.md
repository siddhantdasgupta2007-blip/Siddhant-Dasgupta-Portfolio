# Siddhant Dasgupta — Neo-Brutalist Portfolio

Static portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally

Open `public/index.html` directly, or serve the `public` folder with any static server.

## Structure

- `public/index.html` — page markup/content
- `public/styles.css` — neo-brutalist visual system and responsive layout
- `public/js/app.js` — tagline rotation, cursor, mobile menu and active navigation
- `public/images/siddhu.jpg` — profile photo supplied by Siddhant
- `public/certificates/codemathon-nit-kurukshetra.pdf` — achievement certificate
- `public/certificates/hack-on-titan.pdf` — supplied certificate retained as an asset, not shown in the portfolio
